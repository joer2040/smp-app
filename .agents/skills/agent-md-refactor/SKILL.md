# Agent MD Refactor

## Objetivo

Refactorizar archivos de instrucciones del agente para que sean claros y consistentes.

## Inputs esperados

- Contexto del problema o tarea
- Archivos o areas del repo involucradas
- Restricciones tecnicas o de negocio

## Flujo de trabajo

1. Entender el problema exacto.
2. Reunir el contexto minimo necesario.
3. Aplicar un proceso explicito segun el objetivo de la skill.
4. Producir una salida accionable y verificable.

## Reglas

- No asumir hechos sin revisar contexto suficiente.
- Favorecer cambios pequenos y verificables.
- Explicar decisiones cuando afecten arquitectura, riesgo o alcance.

## Salida esperada

- Diagnostico, plan o resultado utilizable inmediatamente
- Riesgos o supuestos relevantes
- Proximo paso recomendado

## Casos borde

- Contexto incompleto
- Cambios mezclados con trabajo no relacionado
- Falta de permisos, herramientas o datos
