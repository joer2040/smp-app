# SMP App Agent Notes

Project-local skills live in `.agents/skills`.

Default workflow:

- Use `systematic-debugging` for unclear bugs or regressions.
- Use `chrome-devtools` when browser behavior matters.
- Use `commit-work` before committing, pushing, deploying, or opening PRs.
- Use `session-handoff` when pausing long work.
- Use `agent-md-refactor` when agent docs grow or conflict.

Keep changes small, verified, and tied to real `smp-app` files.
